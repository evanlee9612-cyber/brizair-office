## Parts selling-price rule (from the old Parts Inventory Excel, "PRICE RANGE" box)
LG cost (RATE LG MANILA) → customer price:
- ₱0 – 499: cost × 3 + 12% VAT
- ₱500 – 1,499: cost × 2.50 + 12% VAT
- ₱1,500 – 2,999: cost × 2 + 12% VAT
- ₱3,000 and above: cost × 1.75 + 12% VAT
- Rounding: last digit 0–4 → no round-off (end 0); last digit 5–9 → round off (add 1).
The PARTS tab "Customer Price w/ VAT" already has the approved price for most parts — use that first. Use the rule only when the price is blank, and say it is computed.

## The office website (BRIZAIR Office) — what each button does
Login: each person has a 6-digit PIN. Phone: add the site to the Home Screen.
- New job → adds a job to SCHEDULE (date, time, job type, customer, location, units, technician). Open a job to change status: Scheduled → Confirmed → Done (or Moved / Cancelled), print Service Report or Start-up Report.
- Unit in / out → one row in UNIT IN-OUT (IN = delivery from supplier, OUT = installed / sold). Stock NOW updates by itself.
- Part in / out → one row in PART IN-OUT (OUT = part used, write the customer).
- Payment → choose the customer / project from RECEIVABLES, amount, method (Cash, Bank, GCash, Check). Balance updates by itself.
- New contract (Money page) → adds a new account to RECEIVABLES so payments can be tracked.
- Cleaning done → Customers → find customer → "Cleaned" on the unit. Next cleaning = 6 months later, automatic.
- New installation (Customers page) → adds the installed unit to CUSTOMERS (customer, model, serial numbers, installed date). If it came from stock, also record Unit OUT.
- Quotation (Quotes & Invoices) → add items from stock (price fills in from SRP / parts price), installation and other lines, discount, VAT → Save → Print / PDF. Number Q-YYYY-0001.
- Invoice (Quotes & Invoices → New invoice, or "Make invoice" from a quotation) → number INV-YYYY-0001, due date, payment details; can add itself to Money (receivables).
- LG Monthly Report → daily IN / OUT grid like the old Excel, Print / PDF for LG.
- Ask GPT → this chat. Materials for AI → upload price lists, brochures, rules, sample documents, photos; GPT reads them.
- Mistakes: open the record and fix it, or record a correction (e.g. IN to cancel a wrong OUT). Rows are never deleted on the site.
